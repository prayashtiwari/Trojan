# Trojan AI

**An open-source, AI-powered desktop assistant.**

Trojan AI is a personal desktop AI assistant designed to bring intelligent conversations, voice interaction, and a modern desktop experience into one unified application.

Built with Python, React, and OpenRouter API, Trojan aims to make AI interaction more accessible through a dedicated desktop environment with a Jarvis-inspired interface.

## Features

- **AI-Powered Conversations** – Intelligent responses powered by OpenRouter API.
- **Voice Interaction** – Integration with ElevenLabs for AI-generated speech.
- **Modern Desktop Interface** – A sleek, Jarvis-inspired user interface.
- **Python Backend** – Handles the core assistant logic and AI communication.
- **Desktop Application** – Designed to run as a standalone desktop application.

## Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core assistant backend |
| React | User interface |
| OpenRouter API | AI model integration |
| ElevenLabs | Text-to-speech |
| Electron | Desktop application framework |

## Project Status

**Currently under development.**

Trojan AI is an evolving open-source project. Features, architecture, and capabilities are actively being developed and improved.
